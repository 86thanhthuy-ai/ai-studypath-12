BÀI 15: TẠO MÀU CHO CHỮ VÀ NỀN

I. PHẦN LÝ THUYẾT YÊU CẦU CẦN ĐẠT

1. Hệ thống màu sắc trong CSS

CSS cung cấp nhiều cách khác nhau để xác định màu sắc cho thuộc tính color (màu chữ) và background-color (màu nền).

Hệ thống màuCú pháp thiết lậpVí dụGiải thích
Tên màu (Keywords)color: tên_màu;color: red;Sử dụng các tên màu tiếng Anh chuẩn (có khoảng 140 tên).
Hệ Hexadecimalcolor: #RRGGBB;color: #FF0000;Sử dụng mã Hex (16 bit). R: Red, G: Green, B: Blue.
Hệ RGBcolor: rgb(r, g, b);color: rgb(255, 0, 0);r, g, b có giá trị từ 0 đến 255.
Hệ HSLcolor: hsl(h, s, l);color: hsl(0, 100%, 50%);h: Hue (sắc độ), s: Saturation (độ bão hòa), l: Lightness (độ sáng).

2. Bộ chọn tổ hợp (Combinator Selectors)

Bộ chọn tổ hợp dùng để xác định mối quan hệ giữa các phần tử HTML để áp dụng định dạng chính xác hơn.

Loại bộ chọnKý hiệuÝ nghĩaVí dụ
Bộ chọn con cháu(khoảng cách)Chọn tất cả phần tử con, cháu... bên trong phần tử cha.div p { color: blue; } (Tất cả thẻ p nằm trong div)
Bộ chọn con trực tiếp>Chỉ chọn phần tử là con trực tiếp (cấp 1) của cha.div > p { color: red; }
Bộ chọn anh em liền kề+Chọn phần tử anh em nằm ngay sau một phần tử khác.h1 + p { color: green; } (Thẻ p nằm ngay dưới h1)
Bộ chọn anh em chung~Chọn tất cả các phần tử anh em nằm phía sau.h1 ~ p { color: grey; } (Tất cả thẻ p đứng sau h1)

3. Phân tích kết quả thực tế

Giả sử có cấu trúc HTML sau:

<div>

<p>Đoạn văn 1 (Con trực tiếp)</p>

<span>

<p>Đoạn văn 2 (Cháu)</p>

</span>

</div>

Nếu dùng div p { color: blue; }: Cả Đoạn văn 1 và Đoạn văn 2 đều có màu xanh.

Nếu dùng div > p { color: red; }: Chỉ Đoạn văn 1 có màu đỏ, Đoạn văn 2 giữ màu mặc định.
