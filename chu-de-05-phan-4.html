BÀI 13: KHÁI NIỆM, VAI TRÒ CỦA CSS

I. PHẦN LÝ THUYẾT YÊU CẦU CẦN ĐẠT

1. Khái niệm cơ bản về CSS

Nội dungGiải đáp chi tiết
CSS là gì?CSS (Cascading Style Sheets) là ngôn ngữ dùng để tìm và định dạng các thành phần được viết bằng ngôn ngữ đánh dấu (như HTML).
CSS có phải HTML không?KHÔNG. HTML dùng để xây dựng cấu trúc (nội dung), còn CSS dùng để xác định cách hiển thị (màu sắc, phông chữ, bố cục).
Tại sao lại tách biệt?Giúp mã nguồn gọn gàng, dễ quản lý, dễ thay đổi giao diện cho hàng loạt trang web mà không cần sửa từng tệp HTML.

2. Cấu trúc định dạng của CSS

Thành phầnÝ nghĩaVí dụ: p { color: blue; }
Bộ chọn (Selector)Xác định phần tử HTML nào sẽ được áp dụng định dạng.p (áp dụng cho tất cả thẻ đoạn văn)

3. Các cách thiết lập CSS (Ưu và Nhược điểm)

Cách thiết lậpMô tảƯu điểmNhược điểm
Dòng lệnh (Inline CSS)Viết trực tiếp vào thuộc tính style của thẻ HTML.Nhanh, ưu tiên cao nhất cho phần tử đó.Khó quản lý, làm mã HTML trở nên rối rắm.
Trong trang (Internal CSS)Viết trong cặp thẻ <style> nằm ở phần <head>.Kiểm soát tốt giao diện của duy nhất 1 trang web.Không áp dụng được cho các trang web khác trong cùng website.
Tệp ngoài (External CSS)Viết trong tệp riêng .css và liên kết bằng thẻ <link>.Tối ưu nhất, dùng chung 1 file cho nhiều trang, dễ bảo trì.Cần thêm yêu cầu tải tệp từ máy chủ.

4. Vai trò và Ý nghĩa của CSS

Thống nhất giao diện: Tạo sự đồng bộ về màu sắc, kiểu chữ cho toàn bộ website.

Tiết kiệm thời gian: Chỉ cần sửa 1 dòng code trong file CSS, hàng ngàn trang web sẽ thay đổi theo.

Tối ưu hóa: Giúp trang web tải nhanh hơn do trình duyệt có thể lưu tệp CSS vào bộ nhớ đệm (cache).

Trải nghiệm người dùng: Giúp trang web chuyên nghiệp, dễ đọc và đẹp mắt hơn.

5. Ví dụ về câu lệnh định dạng CSS

Yêu cầu: Định dạng cho các tiêu đề h1, h2 và đoạn văn p đều có màu đỏ.

Câu lệnh: h1, h2, p { color: red; } (Ở đây sử dụng bộ chọn nhóm).

2. Phân loại Phông chữ (Font Families)

Phông chữ trong thiết kế Web thường được chia làm 5 loại chính:

- Serif (Có chân): Các chữ cái có gạch nhỏ ở đầu các nét (Ví dụ: Times New Roman). Tạo cảm giác trang trọng.

- Sans-serif (Không chân): Các nét chữ trơn, phẳng (Ví dụ: Arial, Helvetica). Tạo cảm giác hiện đại, dễ đọc trên màn hình.

- Monospace (Đơn cách): Độ rộng các chữ cái bằng nhau (Ví dụ: Courier New). Thường dùng cho mã nguồn.

- Cursive: Mô phỏng chữ viết tay.

- Fantasy: Các phông chữ mang tính nghệ thuật, trang trí.

3. Tính kế thừa (Inheritance) trong CSS

- Khái niệm: Là việc các phần tử con sẽ tự động nhận lại (kế thừa) một số định dạng từ phần tử cha nếu không có định dạng riêng.

- Ví dụ: Nếu bạn đặt body { color: blue; font-family: Arial; }, thì tất cả các thẻ <p>, <h1>, <li> bên trong body đều sẽ có chữ màu xanh và phông Arial mà không cần viết lệnh cho từng thẻ.

4. Thứ tự ưu tiên (Cascading Order)

Khi có nhiều nguồn định dạng cùng áp dụng cho một phần tử, trình duyệt sẽ ưu tiên theo thứ tự từ cao xuống thấp như sau:

Sử dụng !important: Cưỡng ép định dạng, có mức ưu tiên cao nhất.

Inline CSS: Viết trực tiếp trong thuộc tính style của thẻ HTML.

Internal/External CSS: (Ưu tiên bộ chọn cụ thể hơn: ID > Class > Tên thẻ).

Tính kế thừa: Mức ưu tiên thấp nhất.

Mặc định của trình duyệt: Nếu không có định dạng nào, trình duyệt sẽ dùng kiểu mặc định.

5. Ký tự đặc biệt: * và !important

Ký hiệuÝ nghĩaĐộ ưu tiênVí dụ

!importantCưỡng ép: Ép buộc trình duyệt sử dụng định dạng này bất kể quy tắc ưu tiên khác.Cao nhấtp { color: red !important; }

6. Ví dụ câu lệnh tổng hợp

Yêu cầu: Định dạng đoạn văn có phông chữ Sans-serif, cỡ 16px, màu xanh, khoảng cách dòng gấp 1.5 lần và căn lề đều 2 bên.

font-family: Arial, sans-serif;

font-size: 16px;

color: #0000FF;

line-height: 1.5;

text-align: justify;

}
